# Internationalisation

System locale configuration in `system/modules/i18n.nix`.

<<< @/../system/modules/i18n.nix

The system default locale is `en_US.UTF-8` for all `LC_*` categories. Both `en_US.UTF-8` and `sk_SK.UTF-8` locales are generated so that applications can use Slovak formatting (dates, numbers, currency) when configured at the user level.
