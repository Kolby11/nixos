# Machine Configurations

Each physical machine gets its own directory under `system/configurations/`. The device to build is selected at flake evaluation time via the `device` argument.

## How it works

`flake.nix` defines a `mkSystem` helper:

<<< @/../flake.nix{26-35 nix}

Each entry in `nixosConfigurations` calls `mkSystem` with a device name string. That string is passed as `specialArgs.device` all the way down to:

<<< @/../system/configurations/default.nix

`lib.optionals (device == "desktop") [ ./desktop ]` conditionally imports the device's directory only when building for that device. This means only the matching hardware config is ever evaluated — other devices' configs are not included.

## Per-device directory structure

```
system/configurations/<device>/
├── default.nix               # Imports hardware-configuration.nix + ./modules
├── hardware-configuration.nix  # Generated by nixos-generate-config
└── modules/
    ├── default.nix           # Imports device-specific modules
    └── hardware.nix          # GPU drivers and device-specific hardware settings
```

## Available machines

| Device | Description |
|--------|-------------|
| `desktop` | AMD desktop PC |
| `legion` | Lenovo Legion laptop (AMD + NVIDIA hybrid GPU, with specialisations) |
