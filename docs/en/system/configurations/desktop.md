## Hardware configuration

<<< @/../system/configurations/desktop/hardware-configuration.nix

Auto-generated by `nixos-generate-config`. Key details:

- **CPU**: AMD (microcode updates via `hardware.cpu.amd.updateMicrocode`)
- **Boot**: EFI partition at `/boot`, root ext4 at `/`
- **Initramfs modules**: `nvme`, `xhci_pci`, `ahci`, `usbhid`, `sd_mod`
- **DHCP**: enabled on all interfaces by default

## Device-specific modules

<<< @/../system/configurations/desktop/modules/hardware.nix

The desktop uses an AMD GPU exclusively. `services.xserver.videoDrivers = [ "amdgpu" ]` loads the `amdgpu` kernel module and the Mesa userspace driver.

No NVIDIA hybrid GPU configuration is needed here — that is specific to the [Legion](/system/configurations/legion).
