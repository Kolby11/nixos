# Internacionalizácia

Konfigurácia systémového locale v `system/modules/i18n.nix`.

<<< @/../system/modules/i18n.nix

Predvolené systémové locale je `en_US.UTF-8` pre všetky kategórie `LC_*`. Generujú sa obe locale — `en_US.UTF-8` aj `sk_SK.UTF-8` — takže aplikácie môžu používať slovenské formátovanie (dátumy, čísla, mena) ak je nakonfigurované na úrovni používateľa.

::: tip
[Všetky možnosti i18n](https://search.nixos.org/options?channel=25.05&query=i18n)
:::
